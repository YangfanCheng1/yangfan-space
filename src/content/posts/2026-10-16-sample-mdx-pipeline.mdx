This post exists to check the blog pipeline end to end. It's marked `draft: true`, so it shows up in the dev server and is left out of production builds. Delete it once the first real post is written.

## Plain Markdown

Paragraphs, **bold**, _italic_, `inline code` and [links](/projects) all work. So do lists:

- Front matter is validated at build time.
- Reading time is computed from the prose (code blocks don't count).
- Drafts are hidden in production.

1. Write a `.mdx` file in `src/content/posts/`.
2. Commit it.
3. It appears on `/blog` and the home page.

> A blockquote, for the occasional pull quote.

| Feature | Where it lives |
| --- | --- |
| Validation | `src/content/schema.ts` |
| Build plugin | `build/remarkContentMeta.ts` |
| Loader | `src/content/posts.ts` |

## Code

```ts
export function readingMinutes(text: string): number {
  const words = text.trim().split(/\s+/).filter(Boolean).length
  return Math.max(1, Math.ceil(words / 230))
}
```
